# 关于本站

## DNS 解析
本站使用 Cloudflare DNS 服务，Vercel 部署，国内访问较慢一般是受 Free Plan 的 DNS 线路影响。

## 站点美化
本站使用 VitePress 构建，主题为默认主题，首次搭建在2025年。

部分美化参考了 [Yiov/vitepress-doc](https://vitepress.yiov.top/)。
文档切换动画效果参考了 [saicaca/fuwari](https://fuwari.vercel.app/)。
其他动效和 UI 由 AI 生成，我并非前端，如果本站源码公开，你可以查看 [本站 Repo](https://github.com/haotzops/blog-vitepress)
